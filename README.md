# Operação Enxame

Jogo de hordas para o navegador, inspirado no modo temporário **Swarm** do League of Legends. Projeto pessoal, sem fins comerciais. Personagens, armas e nomes são originais.

## Como jogar

Abra o `index.html` no navegador do computador, ou acesse a versão online pelo GitHub Pages.

| Tecla | Ação |
| --- | --- |
| W A S D | Andar |
| E | Habilidade (libera no nível 3) |
| R | Ultimate (libera no nível 6) |
| C | Trocar entre mira automática e mira pelo mouse |
| Tab (segurar) | Tabela de evoluções |
| P ou Esc | Pausar |

As teclas podem ser trocadas em **Opções**. Também dá para jogar com controle (gamepad).

## O que tem no jogo

- 9 lutadores, cada um ligado a um status (Aceleração, Projéteis, Armadura, Vida Máxima, Crítico, Coleta, EXP, Duração e Velocidade)
- 22 armas comuns + 9 armas exclusivas, todas com evolução
- Evolução no estilo do Swarm: arma no nível 5 + a passiva certa + um Cartão de Acesso
- 4 mapas com mecânicas próprias e chefes com várias fases de ataque
- 3 dificuldades: Normal, Difícil e Extremo
- Ouro, melhorias permanentes, objetivos que desbloqueiam conteúdo e recordes
- Som e música gerados por código

O progresso fica salvo no próprio navegador.
